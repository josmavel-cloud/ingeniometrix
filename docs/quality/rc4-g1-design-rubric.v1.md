# RC4 scientific design acceptance rubric v1

Frozen before paid evaluation. No numeric aggregate or schema-only scientific pass.
Each dimension receives PASS, PASS_WITH_LIMITATIONS or FAIL with an output/source
locator. PASS requires a justified executable proposal; honest unresolved inputs
may receive PASS_WITH_LIMITATIONS but cannot authorize a stable design when critical.

| Dimension | Acceptance evidence / failure condition |
| --- | --- |
| INTENT_PRESERVATION | Expected action/product retained; any material substitution explicitly requires user confirmation. |
| SCOPE_APPROPRIATENESS | Level, data, time/resources and complexity considered without invented commitments. |
| THEORY_FRAMEWORK_FIT | Relevant principles/framework separated from methods and software; no mandatory named theory. |
| METHOD_FIT | Each method contributes to a question/objective or validation. |
| METHOD_INTEGRATION | Named dependencies, exchanged outputs and integration; no decorative lists. |
| MIXED_METHODS_VALIDITY | Qualitative + quantitative components and integration point/purpose, or a more accurate label. |
| DATA_FEASIBILITY | Access is confirmed, proposed or pending; no invented access/instruments/sample sizes. |
| PROCEDURAL_EXECUTABILITY | Ordered actions, inputs, outputs and quality checks can guide execution after explicit pending decisions. |
| VALIDATION_STRATEGY | Criteria and comparison/interpretive checks appropriate to the paradigm. |
| EVIDENCE_SUPPORT | Claim-level inspected excerpt supports the decision; a valid pointer alone is insufficient. |
| TRANSFERABILITY | Foreign precedents do not certify local suitability. |
| UNCERTAINTY_DISCLOSURE | Specific unresolved questions and blocking decisions visible. |
| QUESTION_OBJECTIVE_METHOD_ALIGNMENT | Questions/objectives correspond to proposed procedures/analysis. |
| COMPLEXITY_DISCIPLINE | No sophistication unrelated to purpose, level or resources. |
| NOVELTY_DISCIPLINE | No universal novelty from bounded evidence. |

Geospatial comparison uses the exact captured RC3 intake and ledger, not repaired
PDF excerpts or new retrieval. RC3 output is comparator only, never selector input.
Qualitative uses the validated education fixture and its frozen B3 ledger. Applied
education uses a separately labelled evaluation intake with the same frozen education
sources; it tests a different applied purpose, not an additional retrieval claim.
Incomplete input must stop with concrete missing decisions, preferably at zero cost.

Stop paid execution on systemic failure or evidence that broad architecture changes
are required. Maximum per case: one selector, one critic, one targeted repair;
no second critic or automatic full regeneration. Unreviewed repairs are not silently
certified. Global maximum USD8, persistent B4 reservations, no images/documents/search.

## Pre-paid implementation findings

- v1 ran selector+critic twice on rejection, exceeding the one-critic requirement.
- Its repair input contained critique but omitted the original decision, so it could
  regenerate all alternatives instead of patching only the defective alternative.
- Component dependencies had no reference/cycle/dataflow validation.
- Intent adapter missed G2 researchScope/constructs/pendingDecisions and passed raw
  database metadata in user_statements.
- Method pack recorded context-budget exclusions but omitted reasons for sources
  rejected before packing (including the historical S5 unverified full-text excerpts).

These are reproducible contract defects, independent of paid model performance.
